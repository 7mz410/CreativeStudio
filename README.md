Fifteen native apps for macOS, Windows and Linux, written in Rust, for drawing, photos, video,
sound, music, layout, design, documents, spreadsheets, presentations and CAD.

## Get the apps

Install **[mansa (المنصّة)](https://github.com/7mz410/CreativeStudio-mansa/releases/latest)**,
the Creative Studio launcher. It installs and updates every app. Each app's own releases are on
its repository.

## Built on the Crafting Apps

Every app is a fork of one of the open-source, clean-room
[Crafting Apps](https://github.com/storytold) by the [ArtCraft](https://getartcraft.com/) team and
their contributors. Almost all of the work is theirs; please star and support the upstream
projects too. What Creative Studio adds: its own names and identity, the Arabic interface, right-to-left
layout and Arabic text handling, and its own file extensions. We merge upstream regularly and
send fixes back.

Interface translations shared with upstream live in
[7mz410/craft-i18n](https://github.com/7mz410/craft-i18n) (a fork of storytold/craft-i18n).
